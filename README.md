# luantidyssey

A free 3D sandbox RPG for [Luanti](https://www.luanti.org/). Install it and play it on a laptop or a desktop, in Luanti's own 3D world.

The story is Homer's *Odyssey*. The hero is Odysseus. He levels, and he has four skills he upgrades with points. That hero pattern is the only borrow from a 2002 strategy game. The rest is this game.

The look is Greek: stone, bronze, and the sea. Names of places and skills that are not in the poem are original.

## Install

[INSTALL.md](INSTALL.md). Short version: install Luanti 5.6 or newer, put this folder in Luanti's `games` directory as `luantidyssey`, and make a new world with that game selected.

Install zip: [luantidyssey.zip](https://github.com/atongsa/luantidyssey/releases/download/v1.2.0/luantidyssey.zip). Unzip it. The folder is already named `luantidyssey`.
